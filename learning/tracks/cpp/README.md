# Track 3 — C++

> The language of **competitive programming**, **quant trading**, game engines, and
> high-performance systems. Fast, powerful, and closer to the hardware than Python.

**Prerequisite:** Be fluent in one language first (Python — Track 1) and have started DSA
(Track 2). C++ is much easier to learn when you already understand loops, functions, and
recursion — here you're mostly learning *new syntax for ideas you already know*, plus the
new concept of **manual memory and types**.

---

## Why it matters for your goals
- **Competitive programming:** ~90% of top Codeforces competitors use C++ — it's fast
  enough to pass strict time limits, and its **STL** has ready-made data structures.
- **Quant trading:** Most trading firms write their low-latency systems in C++. It's a
  core interview language for quant *developer* roles.
- **Understanding computers:** Pointers and memory teach you what's *really* happening
  under Python's hood.

---

## Syllabus (in order)

### Part A — From Python to C++
1. **Setup & first program** — compilers (`g++`), `main()`, `std::cout`, compiling vs. running
2. **Types & variables** — `int`, `double`, `char`, `bool`; why types are *explicit* here
3. **Control flow** — `if`/`for`/`while` (nearly identical to Python, with `{ }` and `;`)
4. **Functions** — declarations, parameters, return types, pass-by-value vs. reference

### Part B — The C++ core (the new stuff)
5. **References & pointers** — the big new idea; addresses, `*` and `&`
6. **Memory** — the stack vs. the heap, `new`/`delete`, why it matters for speed
7. **Arrays & C-strings**, then `std::string`
8. **The STL containers** — `vector`, `map`, `unordered_map`, `set`, `pair`, `stack`, `queue`
9. **STL algorithms** — `sort`, `binary_search`, `max_element`, iterators
10. **Classes & OOP** — constructors, `this`, encapsulation, inheritance

### Part C — Modern & advanced C++
11. **Templates & generics** — write code that works for any type
12. **RAII & smart pointers** — `unique_ptr`, `shared_ptr` (modern memory safety)
13. **Move semantics & references** — `&&`, why C++ is fast
14. **Modern C++ (11/14/17/20)** — `auto`, range-`for`, lambdas, `constexpr`

### Part D — Competitive C++
15. **Fast I/O** and the competitive-programming template
16. **Re-solving your DSA problems in C++** — speed + STL mastery
