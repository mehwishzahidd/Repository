# Module 01 — Exercises 🏋️

Time to write code yourself! This is where real learning happens.

## How it works

1. Open **`exercises.py`**. It has 8 small functions with the bodies left blank
   for you to fill in. Each has instructions and an example.
2. Replace each `pass` / `return None` with your own code.
3. Check your work any time by running the **auto-checker**:

   ```bash
   python3 learning/01_python_basics/exercises/check.py
   ```

   It runs your functions against test cases and shows ✅ or ❌ for each one,
   with the expected answer when you're wrong. Keep editing and re-running until
   everything is green!

## Tips

- Do them in order — they get slightly harder.
- Stuck? Re-read the matching lesson file. Every exercise maps to a concept you've seen.
- It's normal to get ❌ at first. Read the hint, adjust, re-run. That loop **is** coding.
- When all 8 pass, commit your work with git:
  ```bash
  git add learning/
  git commit -m "Complete Module 01 exercises"
  git push
  ```

The last exercise, **FizzBuzz**, is one of the most famous beginner interview
questions in the world. When you solve it, you've taken your first real step. 🎉
