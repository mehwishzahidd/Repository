# 🚀 Learn to Code: Python, Algorithms & Git

Welcome! This is your personal, hands-on curriculum to go from **complete beginner**
to **ready for a hard CS interview**. We cover three things together:

1. **Python** — the language itself, from `print("hello")` to classes and idioms
2. **Data Structures & Algorithms (DSA)** — the actual content of hard interviews
3. **Git & GitHub** — the tools every professional developer uses every day

> 🎯 **Your goal:** pass a very hard coding interview.
> The path below is the proven route there. Take it one module at a time.

---

## 📋 How to use this curriculum

Every lesson is a real Python file you **run and read**. The workflow is always:

1. **Read** the lesson file top to bottom (the comments explain everything).
2. **Run** it to see the output:
   ```bash
   python3 learning/01_python_basics/01_hello_world.py
   ```
3. **Experiment** — change values, re-run, break things, fix them. This is how you learn.
4. **Do the exercises** for that module, then check your answers automatically.
5. **Commit your progress with git** (you'll learn how — see `GIT_AND_GITHUB.md`).

> 💡 **The golden rule of learning to code:** *type the code yourself, run it, and
> when it breaks, read the error message.* Don't just read — **do**. Errors are not
> failures; they are the feedback loop that teaches you.
