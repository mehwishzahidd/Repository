# P1 — Python programs (Stages 01–02)
Small CLI programs, one file each, each with a `test_*.py`:
`guess.py` (number guessing) · `todo.py` (to-do list saved to JSON) · `wordfreq.py`
(word frequency, top 10) · `convert.py` (unit converter) · `contacts.py` (contact book
with a dataclass + class) · `expenses.py` (CSV in, summary out, bad rows reported).

**Done when:** you can write any of these from a blank file and explain every line.
**Attacks (do by hand):** empty input · file missing · letters where a number is expected
· a CSV with a broken row · Ctrl-C mid-run.
