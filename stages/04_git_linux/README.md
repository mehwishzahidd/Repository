# Stage 04 — Git, GitHub, the shell and Linux

> **Roadmap Group 1 · general software skills.** See [`ROADMAP.md`](../../ROADMAP.md) for the full checklist behind this stage.

Every real codebase, every job, every project from here on lives in git and runs on Linux. Learn it now and use it daily so it is invisible by the time it matters.

**Prerequisite:** Stage 03 done and its checkpoint ticked. Don't skip ahead — every
stage assumes the one before it.

---

## What you learn

### Git
init · add · commit · log · diff · branches · merge · rebase (basics) · resolving conflicts · `.gitignore` · undoing things

### GitHub
remotes · push/pull · pull requests · code review · issues · Actions (a first glance)

### The shell
navigating · pipes & redirection · `grep`, `find`, `sed`, `awk` basics · environment variables · scripts

### Linux
processes (`ps`, `top`, `kill`) · permissions · file descriptors · `/proc` · package managers · SSH · reading logs

### Tooling
IDE + debugger (breakpoints, stepping) · virtual envs · reading documentation efficiently

---

## ✅ Checkpoint — you're done with this stage when

- [ ] Commit every day for two weeks.
- [ ] Open and merge a pull request on your own repo with a review comment.
- [ ] Recover from: a bad commit, a merge conflict, a detached HEAD.
- [ ] Use the debugger to find a bug instead of `print`.
