# Stage 02 — Exercises

Twelve exercises, one per lesson idea, ending with your first LRU cache (v1, on an
`OrderedDict`). Fill in `exercises.py`, then check:

```bash
python3 stages/02_programming/exercises/check.py
```

Rules that make these count:
1. Decide the edge cases **before** writing code (empty? missing? duplicate?). The
   checker tests them.
2. Write at least one `pytest` test of your own for each function in a
   `test_exercises.py` next to it, and run `python3 -m pytest stages/02_programming`.
3. When all 12 pass, commit: `git add stages/ && git commit -m 'Finish Stage 02'`.
