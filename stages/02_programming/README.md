# Stage 02 — Programming — classes, files, the standard library, stronger Python

> **Roadmap Groups 1 & 3.** See [`ROADMAP.md`](../../ROADMAP.md) for the full checklist behind this stage.

Stage 01 taught you the atoms. This stage makes Python *yours*: you stop thinking about syntax and start thinking about the problem. It is also where clean, production-quality habits begin.

**Prerequisite:** Stage 01 done and its checkpoint ticked. Don't skip ahead — every
stage assumes the one before it.

---

## What you learn

### Organising code
dictionaries, sets, tuples in anger · scope · modules & packages · virtual environments · `pip`

### Errors & files
exceptions, `try/except/finally` · reading & writing files · JSON · `pathlib`

### Classes
classes, objects, `__init__`, methods · inheritance vs composition · `dataclasses` · `__repr__`, `__eq__`

### Stronger Python
comprehensions · iterators & generators · decorators · context managers · type hints

### The standard library
`collections` (Counter, deque, defaultdict) · `heapq` · `bisect` · `functools` · `itertools`

### Production habits (Group 3)
clear names · small functions · input validation · error handling · `pytest` basics · always ask: empty input? capacity 0? duplicates?

- [ ] Write a 150-line program with classes, files and error handling from a blank file.
